# KafkaDemo

Simple Spring Boot application integrated with:

- Apache Kafka
- PostgreSQL
- Docker Compose
- Kafka UI

---

# Technologies Used

- Java 21
- Spring Boot 3
- Spring Kafka
- Spring Data JPA
- PostgreSQL
- Docker
- Kafka UI

└── model

Make sure below software is installed:
